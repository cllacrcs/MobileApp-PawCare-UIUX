## ୨୧ About the Project

**PawCare** is an individual UI/UX design project exploring a mobile application experience for pet care.

The project focuses on interface design, user flows, and creating a digital experience that feels approachable and easy to navigate. It was developed as an opportunity to explore the design process and translate an idea into an interactive prototype.

## ୨୧ Project Goals

- Explore a user-friendly mobile interface for a pet-care application.
- Organize screens and navigation into a clear user flow.
- Develop interface layouts with attention to consistency and usability.
- Turn design concepts into an interactive Figma prototype.
